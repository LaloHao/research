Research Connector

Vincular con Research

En Research abre Ajustes → Aplicación → «Extensión del navegador», pulsa «Vincular extensión» y escribe aquí el código. Después confirma en la ventana de Research.

Dirección de la API local

La de Research en este equipo; cámbiala solo si cambiaste el puerto en Ajustes → Aplicación → API local. La extensión solo se conecta a 127.0.0.1 o localhost.

Atajo de teclado

Alt+Mayús+R agrega la pestaña actual sin abrir la ventana emergente (el icono muestra ✓ o !). Puedes cambiarlo en la página de atajos de extensiones del navegador.
